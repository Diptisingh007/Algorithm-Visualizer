# AlgoVista 🚀

**AlgoVista** is an interactive **Algorithm Visualizer** built with React. It helps students and developers understand how popular algorithms work by visualizing their execution step by step.

Instead of only reading code or watching static examples, AlgoVista lets you **see algorithms in action**.

## ✨ Features

* 📊 **Sorting Algorithm Visualization**

  * Bubble Sort
  * Selection Sort
  * Insertion Sort
  * Merge Sort
  * Quick Sort

* 🔍 **Searching Algorithm Visualization**

  * Linear Search
  * Binary Search

* 🌳 **Data Structure Visualization**

  * Binary Search Tree
  * Tree Traversals

* 🎮 Interactive controls

  * Generate new data
  * Start / pause visualization
  * Control animation speed
  * Reset the visualization

* 🎨 Clean and responsive interface

* ⚡ Step-by-step algorithm animations

* 📱 Responsive design for different screen sizes

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Diptisingh007/Algorithm.git
```

### 2. Navigate to the project

```bash
cd AlgoVista
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local URL provided by Vite.

## 📈 How It Works

AlgoVista represents algorithm operations visually.

For example, during **Bubble Sort**, the application highlights the elements being compared and shows their positions changing as the algorithm progresses.

This makes concepts such as:

* Comparisons
* Swapping
* Traversal
* Searching
* Recursion
* Time complexity

easier to understand.

## 🎯 Purpose

The main goal of AlgoVista is to make **Data Structures and Algorithms easier to learn through visualization**.

It can be useful for:

* Students learning DSA
* Interview preparation
* Understanding algorithm complexity
* Teaching algorithms
* Developers revising fundamental concepts
